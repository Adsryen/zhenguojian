# 真果鉴 v2 候选正式版（RC）复验清单

> 对应版本：v2.0.0-alpha.21（构建提交 b82fbde）及之后的 RC。逐条过完全部 ✔ 即视为 v2 功能对齐 v1，可打 v2.0.0 正式 tag。
> 获取方式：仓库 Releases 下载 `zhenGuoJian-v2-app.zip`（程序本体）+ `zhenGuoJian-v2-runtime.zip`（mpv/ffmpeg，仅首次需要）；日常升级也可用程序内「设置 → 更新」。

## 0. 安装与升级
- [ ] 解压 app.zip 到任意目录（如 `D:\真果鉴v2\`），把 runtime.zip 的 `runtime\` 文件夹整体放进 exe 同级目录
- [ ] 设置 → 关于：打包提交显示 revision（非「未知」），版本号与所下 tag 一致
- [ ] 设置 → 更新 → 检查更新：能返回结果（已最新或提示新版）；「检查测试版」开关可发现 alpha/RC
- [ ] 老 v1 数据迁移：若之前用过 v1，追剧/历史首次启动自动导入（v1 `watch-library.json` 原文件不被改写）

## 1. 剧库推荐（首页）
- [ ] 首次进入即有海报墙（红果库 lane），无「示例数据」横幅
- [ ] 右侧排行榜侧栏：默认第一名榜；可切换榜单；「加载更多」追加不重复；榜单封面加载正常
- [ ] 点击海报 → 详情页；首页可下拉刷新（下拉手势出转圈）

## 2. 找剧
- [ ] 顶部站源芯片可切换（含拖拽排序后的顺序，红果默认第一个）；18+ 源带红色徽章且出厂关闭
- [ ] 分类芯片随站源变化（红果：真人剧/漫剧/AI剧…；柚子：其专属栏目）
- [ ] 翻页不重复；首屏大卡（hero）与网格不重复同一部
- [ ] 封面显示正常（首次大批加载若出红条「部分封面加载失败」→ 点「复制诊断」并把内容反馈开发者）

## 3. 搜索
- [ ] 单源搜索、分页、「加载更多」正常
- [ ] 输入时红果（或全部来源）出联想下拉：↑↓/Enter/Esc 键盘链路可用
- [ ] 勾「全部来源」：按源分组流式出结果，某源失败只影响该组并有重试按钮
- [ ] 最近搜索记录保留并可清

## 4. 详情页
- [ ] 简介/演员条：点演员跳创作者页，作品列表 tab/子 tab/排序/翻页可用
- [ ] 多季剧出季切换条，切季后选集列表跟随
- [ ] 追剧（+）/看过（✓）按钮：操作后重启程序状态保持；日历页同剧同状态
- [ ] 「下载」真实入队：toast 计数、可从提示跳下载页；磁盘满等核心错误有中文提示
- [ ] VIP 集提示、预告/花絮占位不报错

## 5. 播放
- [ ] 画面内嵌在窗口内（不弹独立 mpv 窗）；缩放窗口画面跟随；切走页签再切回不黑屏
- [ ] 若嵌入失效（画面区空白/视频在独立窗）：属回退行为，记录并反馈；`ZHENGUO_NO_EMBED=1` 可强制旧独立窗行为
- [ ] 弹幕开关 + 计数显示；ASS 弹幕滚动观感与 v1 一致
- [ ] 快捷键：Space 暂停 / ←→ 5s / F 全屏 / M 静音 / S 弹幕 / Esc 退全屏或关窗；`?` 出快捷键帮助
- [ ] 选集面板（右侧）：可点选、当前集高亮；播完自动连播下一集（可关）
- [ ] 画质切换：重开流原位续播；倍速 0.5–3.0；音量 0–100 重启记忆
- [ ] 看到一半关程序 → 首页/历史「继续播放」从中断点续播
- [ ] 网络卡断后有自动恢复（不闪退）；播放失败提示为中文可读文案

## 6. 追剧日历
- [ ] 页面可滚动；日期横条可翻页；「全部/男频/女频」筛选生效
- [ ] 追剧/预约按钮真实生效（重启保持），失败出红条提示
- [ ] 点上/下线条目进详情

## 7. 下载与合并
- [ ] 统计条：状态筛选 chips 计数与列表一致
- [ ] 新建任务（画质档位：自动/1080/720/540）、暂停/继续/重试/取消、速度显示
- [ ] 下载完成的集可合并；合并中重启程序 → 重启后合并记录还在（中断的标「重启时中断」可重试）
- [ ] 归档 tab：显示真实下载目录分组（v1 存量文件也应出现）；「打开所在目录」跳 explorer
- [ ] 归档/取消归档往返正常

## 8. 设置
- [ ] 站源卡片：开关可点（整卡热区）、18+ 徽章、备注省略号 hover 全文、拖拽排序后找剧/搜索芯片顺序跟随
- [ ] 播放偏好即时生效（倍速/音量/弹幕默认）
- [ ] 网络与下载：代理模式（自动/直连/手动）保存生效；目录并发/下载并发/按源分道可调
- [ ] 青空账号：登录对话框出滑块，人工拖动可登录（登录后在线播放解除限制）；退出账号可用
- [ ] 界面语言 中/EN 切换全站生效；主题 跟随/亮/暗

## 9. 关闭与托盘
- [ ] 点 X：主窗隐藏、任务栏托盘图标在（「真」图标），下载任务后台继续
- [ ] 双击托盘恢复窗口；托盘右键：显示主窗口 / 检查更新 / 退出 全可用
- [ ] 「退出」后进程真正结束（托盘消失）

## 已知限制（不算回归失败）
- 全部来源搜索用单字（如「我」）个别上游（青空）会报「目录数据格式无效/数据过大」，两字以上正常
- 黄果视频/黄豆无服务端关键词搜索（本地目录匹配，命中率有限）
- 柚子 18+ 源出厂关闭，需设置手动打开
- 弹幕颜色为全局样式（上游不下发逐条颜色，与 v1 相同）
- 下载根目录在 v2 位于 `%LOCALAPPDATA%\ZhenguoJian\downloads`（与 v1 的 exe 同级 `下载` 不同；归档页会同时显示真实路径）
