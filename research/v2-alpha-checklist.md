## 6. 播放与弹幕

前置（自备 mpv）：

- [ ] 把 **v1 release 包里整个 `runtime\mpv\` 目录**（mpv.exe + mpv-2.dll 等同级 DLL）拷到 v2 exe 同级
      `runtime\mpv\`；或设环境变量 `ZHENGUO_MPV` 指向 mpv 可执行文件。
      查找顺序：exe 下 `runtime/mpv/mpv.exe` → `ZHENGUO_MPV` → PATH。
- [ ] 未配置时的报错应可读：「mpv: 找不到 mpv 可执行文件…」；只拷 exe 少 DLL 时报
      「播放器缺少组件 …要和 mpv.exe 放在同一个目录（runtime\mpv）」——两条文案都算正常表现。

真播：

- [ ] 红果：任一剧**第 1 集**点播，mpv 独立窗口出画面有声。
- [ ] 柚子：任一集点播（需第 3 节已开启柚子），取流不报 403。
- [ ] 控制：倍速、音量、暂停、seek 均生效；音量/倍速**下次启动记忆**
      （v2 前端 localStorage 语义，见第 8 节）。
- [ ] 弹幕：播放页开「弹幕」→ mpv 内出现**字幕轨弹幕**（ASS 路线，DOM 不画弹幕），条数徽章显示「弹幕 N 条」；关闭后消失。
- [ ] 断线自动重建：播放中用任务管理器**杀掉 mpv 进程**，回播放页再点播放/切集——
      应用应自动重建播放器继续工作，**不需要重启程序**。
- [ ] 播放页关闭按钮 = 关播放器并返回原页面，主窗不闪退。

## 7. 网络设置

设置 → 网络与下载：

- [ ] 代理模式三档：自动 / 直连 / 手动。

- [ ] 还原「直连」保存，浏览恢复正常。

## 8. 已知缺口（alpha 预期缺失，勿报 bug）

- **下载队列页**（导航「下载」）、**剧库推荐页**：alpha 为占位页（PlaceholderView），开发中（V2-6）。
- **日历 overlay**（v1 日期弹层）未移植；导航「日历/预约」入口以 `/reserve` 页两 tab 的基础版呈现。
- **mpv 为独立窗口**（非窗口内嵌），WidProvider 内嵌是 V2-6 待办——独立弹窗属预期。
- **音量/倍速记忆为 v2 前端 localStorage 语义**，与 v1 配置不互通，两边数值不一致属预期。
- **弹幕真实色**未接入（V2-6 待办），alpha 按 ASS 默认样式渲染；颜色与 v1 有出入不计缺陷。
