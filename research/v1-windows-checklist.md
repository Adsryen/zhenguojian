# V1 验收清单（Windows 发行环境）

本机 Linux 已完成：逐源协议冒烟（14 源目录/详情/取流，见 `.trellis` v1 notes）、UI 离屏冒烟与截图合集、D1 归档目录实测、soraniAccount 行协议。以下项目只有 Windows 打包环境能覆盖，请按序执行：

## 1. 打包自检（9 步，原 10 步去掉 play）
```bat
python build\build.py
python build\package.py
```
resources / library / newseries / search / detail / preload / download / decrypt / merge 全绿；
任一环节失败先对照 `AI_BUILD.md` 的取流告警（签名/请求改动后必须复测 1080P）。
原 `play` 步已移除：它会在自检中途弹出 mpv 窗口播一段视频，观感突兀；
取流链路已由 detail/preload/download/decrypt/merge 覆盖，真实播放在第 2 节人工验证。

## 2. 逐源真播放抽样（每源 1 部随机剧第 1 集）
- 红果：在线播放 + 弹幕显示 + 切集（验证 P1 右栏与预缓冲在真机不遮挡视频）
- 黄豆 / 野果 / 禁果 / 禁果短剧 / 鬼片 / 韩小圈 / 黑桃 / 帝果 / 青空 / 剧果 / 黄果·视频 / 黄果·AI / 黄果·旧版：
  详情页取流可播、清晰度菜单按源实际档位生效（`player/quality` 持久化）。
- 帝果、黄果·视频在 Linux 冒烟为站点超时，如 Windows 同样超时则判定上游不可达，不计入缺陷。

## 3. 下载-解密-合并回归
每新源下载 1 集 → 队列状态 pill → 完成后归档分组出现「剧名/第N集.mp4」→
合并 mkv 落「合并/剧名」→ 播放成品。重点确认失败任务的 ⟳ 按钮语义（当前实现=重新入队，
若期望"断点续传"请在验收时提出）。

## 4. 站源开关
设置 > 站源：关一个源 → 找剧切换器/搜索不再出现该源，重开恢复；重启后开关保持
（source_prefs.json 与 sources.json 同目录）。

## 5. 青空账号
设置 > 站源 > 站源账号 → 滑块验证码真人拖动登录 → 青空 resolve 不再提示登录；
退出登录恢复匿名可逛不可播。

## 6. 历史与追剧
观看历史按 今天/昨天/更早 分段；追剧有更新置顶角标；后台 30 分钟检查在桌面常驻时正常。
